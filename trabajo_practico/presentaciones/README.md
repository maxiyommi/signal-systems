# Presentaciones del TP

Presentaciones interactivas del trabajo práctico RIR-API, **en el orden en que conviene leerlas**. Se abren en el navegador (flechas para avanzar, `S` para notas del orador, `F` pantalla completa). Cada una empieza con una slide "Dónde estamos" (material de apoyo previo) y termina con "Qué sigue" (próxima presentación y documentos).
